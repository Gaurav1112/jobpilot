**Goal:**
1. Every morning a GitHub Actions job in a PRIVATE data repo pulls the encrypted state, runs the daily pipeline and the
   freelance `am` window, compacts, and commits a new encrypted generation, whatever the Mac is doing. The Mac is
   untouched (it keeps `~/.jobpilot` and its launchd jobs).
2. A deterministic report compares a week of hosted runs with the Mac's, per source, against the spec's numeric
   criteria C1–C7.

**Architecture (H1 + H2 slice of spec §2):**
- New code lives in `src/app/hosted/` (state format, state store, wrapper, CLI) and `src/app/hosted/shadow/`
  (comparator). Small, flagged changes go into the pipelines (`run`, `run-freelance`: a SIGTERM stop between steps, a
  machine-readable summary, a window restriction, source skips), the broker's user agent (S10), the secrets interface
  (`envSecrets`) and the notifier (a file notifier for hosted runs).
- **Everything that differs on the runner is selected by `JOBPILOT_RUN_ENV=hosted`.** With the variable unset, every
  existing behaviour, golden and test stays byte-identical (the daily-identity golden included).
- GitHub is reached only through the injected `GitHubClient`: the real one shells out to the `gh` CLI (present on the
  runner; the user's own login on a laptop) with the token in the environment, never in argv. Tests use the
  directory-backed `dirGitHub` (also the dry-run backend). No test touches the network.
- The wrapper runs each pipeline as a **child process** (`node --import tsx src/bin.ts run …`) with its own minimal
  environment: the state and pack keys and the GitHub token never reach a pipeline; Gmail's three values reach only the
  freelance child.

**Tech stack:** TypeScript on Node 24 (ESM, strict), `node:crypto` (AES-256-GCM), `node:zlib` (zstd level 3; gzip
allowed by the format), better-sqlite3 (`backup`, `quick_check`), zod 4.6.5, commander, yaml, vitest. **No new
dependency.**

## Global Constraints

Copied verbatim from the spec (§1.3, "Constraints (binding, copied from the brief)"):

- Deterministic, no LLM, no paid keys.
- Honest UA, no evasion. A source blocked from cloud IPs just reports a named problem.
- **The DB is compacted inside every hosted run** with `store compact`. Hosted keeps 1 daily run (S5, research §1 numbers).
- **State integrity:**
  - a single concurrency group;
  - an atomic upload of the encrypted DB release asset with a checksum;
  - the previous version kept for rollback;
  - a run that fails before upload never replaces good state.
- **Secrets:**
  - the Gmail refresh token is an Actions secret;
  - the pack is encrypted in the data repo;
  - nothing is ever echoed;
  - `::add-mask::` is used where needed.
- **The snapshot** meets the UX spec's content rules and the 400 px rule. It contains nothing decryptable without the passphrase, and it has a size budget (§3.6).
- **The public repo** gets only generic code and an example workflow with all-fictional values.
- **The live Mac setup** (launchd, `~/.jobpilot`) keeps working unchanged until the switch.
- **Branch code never migrates `~/.jobpilot`.**
- Carried over from earlier specs: never auto-submits, robots.txt and terms honoured, `node --run` (never `pnpm <script>`), exact dependency versions, Node 24.

**Exemption, stated so it's not a silent conflict.** UX §3 requires "works without JS" and "127.0.0.1 only". Those still
bind the local dashboard. The encrypted Pages snapshot can't work without JS, because decryption is JS. It is a separate
read-and-triage surface with its own rules (§3.7). It obeys the UX content rules, the 400 px rule, the 44 px targets and

## Phase H1: hosted runs (shadow)

### Task 1: JPST1, the sealed format (header, STREAM chunks, key ids, typed errors)

**Files:** create `src/app/hosted/jpst.ts`; test `tests/hosted/jpst.test.ts`.

**Interfaces:**

```ts
export const JPST_MAGIC = 'JPST1\n';
export const DEFAULT_CHUNK = 4 * 1024 * 1024;
export type JpstCodec = 'zstd' | 'gzip';
export interface JpstHeader { readonly v: 1; readonly codec: JpstCodec; readonly level: number; readonly chunk: number; readonly keyId: string; readonly nonce: string }
export type JpstErrorCode = 'bad-magic' | 'bad-header' | 'wrong-key' | 'truncated' | 'extended' | 'reordered' | 'tampered';
export class JpstError extends Error { readonly code: JpstErrorCode }
export function keyIdOf(key: Buffer): string;                       // first 4 bytes of sha256(key), hex
export function decodeKey(b64: string, name: string): Buffer;       // 32 bytes, canonical standard base64, else throws naming `name` only
export interface SealOptions { readonly codec?: JpstCodec; readonly level?: number; readonly chunk?: number; readonly noncePrefix?: Buffer }
export function sealTransform(key: Buffer, o?: SealOptions): Transform;   // input: the COMPRESSED payload; output: header + sealed chunks
export function openTransform(key: Buffer, onHeader?: (h: JpstHeader) => void): Transform;
export function parseHeader(buf: Buffer): { header: JpstHeader; length: number } | null;  // null: need more bytes
export function readHeaderOf(file: string): JpstHeader;            // reads at most the first 1024 bytes
export function sealBuffer(key: Buffer, plain: Buffer, o?: SealOptions): Promise<Buffer>;
export function openBuffer(key: Buffer, sealed: Buffer): Promise<Buffer>;
```

The format (spec §3.3): line `JPST1\n`, then the canonical header line (keys sorted: `chunk, codec, keyId, level,
nonce, v`), then chunks. Chunk `i` = AES-256-GCM(key, nonce = 8-byte prefix ‖ uint32BE(i), AAD = sha256(header bytes)
‖ uint32BE(i) ‖ final-flag byte) of up to `chunk` bytes, written as ciphertext ‖ 16-byte tag. Every chunk but the last
holds exactly `chunk` bytes; the last one is flagged final (an empty payload is one empty final chunk, 16 bytes). The
writer holds one byte back so the last full chunk is sealed final only when the input really ends.

const headerLen = (b: Buffer) => b.indexOf(0x0a, 6) + 1;
const UNIT = 64 + 16;

describe('JPST1 known answers (Node 24 AES-256-GCM)', () => {
  it('seals the vector to fixed bytes', async () => {

    expect(s.subarray(headerLen(s) + 64, headerLen(s) + 80).toString('hex')).toBe('2c45846b86d163083bdab155a730b41f');
    expect((await openBuffer(KEY, s)).equals(PLAIN)).toBe(true);

import { createCipheriv, createDecipheriv, createHash, randomBytes } from 'node:crypto';
import { closeSync, openSync, readSync } from 'node:fs';
import { Transform, type TransformCallback } from 'node:stream';

/**
 * JPST1 (hosted spec §3.3): the sealed format of the hosted state and pack. A header line, then the compressed payload
 * in chunks, each AES-256-GCM with nonce = 8-byte random prefix ‖ uint32BE counter and AAD = sha256(header) ‖ counter ‖
 * final flag: the STREAM construction, so reordering, truncation and extension all fail authentication. On a failure
 * the reader tries cheap alternatives (another position, the other flag) only to NAME the failure; nothing that fails
 * authentication is ever emitted. Messages name chunk numbers and key ids, never key bytes or plaintext.
 */
export const JPST_MAGIC = 'JPST1\n';
export const DEFAULT_CHUNK = 4 * 1024 * 1024;
const TAG = 16;
const MAX_CHUNK = 64 * 1024 * 1024;

export type JpstCodec = 'zstd' | 'gzip';
export interface JpstHeader {
  readonly v: 1;
  readonly codec: JpstCodec;
  readonly level: number;
  readonly chunk: number;
  readonly keyId: string;
  readonly nonce: string;
}
export type JpstErrorCode = 'bad-magic' | 'bad-header' | 'wrong-key' | 'truncated' | 'extended' | 'reordered' | 'tampered';
export class JpstError extends Error {
  override readonly name = 'JpstError';
  constructor(readonly code: JpstErrorCode, message: string) {
    super(message);
  }
}

export const keyIdOf = (key: Buffer): string => createHash('sha256').update(key).digest('hex').slice(0, 8);

export function decodeKey(b64: string, name: string): Buffer {
  const t = b64.trim();
  const key = Buffer.from(t, 'base64');
  if (key.length !== 32 || key.toString('base64') !== t) throw new Error(`${name}: expected 32 bytes in standard base64`);
  return key;
}

function headerBytes(h: JpstHeader): Buffer {
  const json = `{"chunk":${h.chunk},"codec":${JSON.stringify(h.codec)},"keyId":${JSON.stringify(h.keyId)},"level":${h.level},"nonce":${JSON.stringify(h.nonce)},"v":1}`;
  return Buffer.from(`${JPST_MAGIC}${json}\n`, 'utf8');
}
function nonceOf(prefix: Buffer, counter: number): Buffer {
  const n = Buffer.alloc(12);
  prefix.copy(n, 0, 0, 8);
  n.writeUInt32BE(counter, 8);
  return n;
}
function aadOf(headerHash: Buffer, counter: number, final: boolean): Buffer {
  const a = Buffer.alloc(37);
  headerHash.copy(a, 0);
  a.writeUInt32BE(counter, 32);
  a[36] = final ? 1 : 0;
  return a;
}
function sealChunk(key: Buffer, prefix: Buffer, hh: Buffer, counter: number, final: boolean, plain: Buffer): Buffer {
  const c = createCipheriv('aes-256-gcm', key, nonceOf(prefix, counter));
  c.setAAD(aadOf(hh, counter, final));
  return Buffer.concat([c.update(plain), c.final(), c.getAuthTag()]);
}
function tryOpen(key: Buffer, prefix: Buffer, hh: Buffer, counter: number, final: boolean, sealed: Buffer): Buffer | null {
  if (sealed.length < TAG) return null;
  try {
    const d = createDecipheriv('aes-256-gcm', key, nonceOf(prefix, counter));
    d.setAAD(aadOf(hh, counter, final));
    d.setAuthTag(sealed.subarray(sealed.length - TAG));
    return Buffer.concat([d.update(sealed.subarray(0, sealed.length - TAG)), d.final()]);
  } catch {
    return null;
  }
}

export interface SealOptions {
  readonly codec?: JpstCodec;
  readonly level?: number;
  readonly chunk?: number;
  /** Tests only: the 8-byte nonce prefix (default: 8 random bytes per file). */
  readonly noncePrefix?: Buffer;
}

export function sealTransform(key: Buffer, o: SealOptions = {}): Transform {
  const chunk = o.chunk ?? DEFAULT_CHUNK;
  if (!Number.isInteger(chunk) || chunk < 16 || chunk > MAX_CHUNK) throw new Error(`jpst: chunk size ${chunk} out of range`);
  const prefix = o.noncePrefix ?? randomBytes(8);
  if (prefix.length !== 8) throw new Error('jpst: the nonce prefix is 8 bytes');
  const header = headerBytes({ v: 1, codec: o.codec ?? 'zstd', level: o.level ?? 3, chunk, keyId: keyIdOf(key), nonce: prefix.toString('hex') });
  const hh = createHash('sha256').update(header).digest();
  let pending = Buffer.alloc(0);
  let counter = 0;
  let headerOut = false;
  const emit = (t: Transform, final: boolean, plain: Buffer): void => {
    if (counter > 0xffffffff) throw new Error('jpst: too many chunks');
    t.push(sealChunk(key, prefix, hh, counter, final, plain));
    counter += 1;
  };
  return new Transform({
    transform(data: Buffer, _enc: BufferEncoding, cb: TransformCallback) {
      if (!headerOut) {
        this.push(header);
        headerOut = true;
      }
      pending = Buffer.concat([pending, data]);
      while (pending.length > chunk) {
        emit(this, false, pending.subarray(0, chunk));
        pending = pending.subarray(chunk);
      }
      cb();
    },
    flush(cb: TransformCallback) {
      if (!headerOut) this.push(header);
      emit(this, true, pending);
      cb();
    },
  });
}

export function parseHeader(buf: Buffer): { header: JpstHeader; length: number } | null {
  if (buf.length < JPST_MAGIC.length) return null;
  if (buf.subarray(0, JPST_MAGIC.length).toString('latin1') !== JPST_MAGIC) throw new JpstError('bad-magic', 'jpst: not a JPST1 file');
  const nl = buf.indexOf(0x0a, JPST_MAGIC.length);
  if (nl < 0) {
    if (buf.length > 1024) throw new JpstError('bad-header', 'jpst: header line longer than 1024 bytes');
    return null;
  }
  let x: Partial<JpstHeader>;
  try {
    x = JSON.parse(buf.subarray(JPST_MAGIC.length, nl).toString('utf8')) as Partial<JpstHeader>;
  } catch {
    throw new JpstError('bad-header', 'jpst: the header is not JSON');
  }
  const ok =
    x.v === 1 && (x.codec === 'zstd' || x.codec === 'gzip') && Number.isInteger(x.level) && Number.isInteger(x.chunk) &&
    (x.chunk as number) >= 16 && (x.chunk as number) <= MAX_CHUNK && /^[0-9a-f]{8}$/.test(x.keyId ?? '') && /^[0-9a-f]{16}$/.test(x.nonce ?? '');
  if (!ok) throw new JpstError('bad-header', 'jpst: the header fields are invalid');
  const header = x as JpstHeader;
  if (!headerBytes(header).equals(buf.subarray(0, nl + 1))) throw new JpstError('bad-header', 'jpst: the header is not canonical');
  return { header, length: nl + 1 };
}

export function readHeaderOf(file: string): JpstHeader {
  const fd = openSync(file, 'r');
  try {
    const b = Buffer.alloc(1024);
    const n = readSync(fd, b, 0, 1024, 0);
    const p = parseHeader(b.subarray(0, n));
    if (p === null) throw new JpstError('truncated', 'jpst: the file ends inside its header');
    return p.header;
  } finally {
    closeSync(fd);
  }
}

export function openTransform(key: Buffer, onHeader?: (h: JpstHeader) => void): Transform {
  let head = Buffer.alloc(0);
  let header: JpstHeader | undefined;
  let hh = Buffer.alloc(0);
  let prefix = Buffer.alloc(0);
  let unit = 0;
  let pending = Buffer.alloc(0);
  let counter = 0;
  /** A non-final chunk failed for no reason found yet: the rest is kept (at most 16 units) to tell an extension. */
  let suspect = false;
  const misplaced = (sealed: Buffer, at: number): number | null => {
    for (let c = 0; c <= at + 64; c++) {
      if (c === at) continue;
      if (tryOpen(key, prefix, hh, c, false, sealed) !== null || tryOpen(key, prefix, hh, c, true, sealed) !== null) return c;
    }
    return null;
  };
  const tampered = (): JpstError => new JpstError('tampered', `jpst: chunk ${counter} failed authentication (tampered or corrupt)`);
  const extended = (): JpstError => new JpstError('extended', `jpst: data follows the final chunk (${counter})`);
  const failNonFinal = (sealed: Buffer): void => {
    const c = misplaced(sealed, counter);
    if (c !== null) throw new JpstError('reordered', `jpst: chunk ${counter} belongs at position ${c}`);
    if (tryOpen(key, prefix, hh, counter, true, sealed) !== null) throw extended();
    suspect = true;
  };
  const finish = (t: Transform): void => {
    if (suspect) {
      // whole sealed chunks appended after a short final one: the final chunk is what is left modulo a unit
      const len = pending.length % unit === 0 ? unit : pending.length % unit;
      if (tryOpen(key, prefix, hh, counter, true, pending.subarray(0, len)) !== null) throw extended();
      throw tampered();
    }
    if (pending.length === 0 && counter > 0) throw new JpstError('truncated', `jpst: the file ends after chunk ${counter - 1}, which is not the final one`);
    const plain = tryOpen(key, prefix, hh, counter, true, pending);
    if (plain === null) {
      if (tryOpen(key, prefix, hh, counter, false, pending) !== null) throw new JpstError('truncated', `jpst: the file ends after chunk ${counter}, which is not the final one`);
      const c = misplaced(pending, counter);
      if (c !== null) throw new JpstError('reordered', `jpst: chunk ${counter} belongs at position ${c}`);
      throw tampered();
    }
    if (plain.length > 0) t.push(plain);
  };
  return new Transform({
    transform(data: Buffer, _enc: BufferEncoding, cb: TransformCallback) {
      try {
        if (header === undefined) {
          head = Buffer.concat([head, data]);
          const p = parseHeader(head);
          if (p === null) return cb();
          if (p.header.keyId !== keyIdOf(key)) throw new JpstError('wrong-key', `jpst: wrong key (the file was sealed with key ${p.header.keyId})`);
          header = p.header;
          onHeader?.(header);
          hh = createHash('sha256').update(head.subarray(0, p.length)).digest();
          prefix = Buffer.from(header.nonce, 'hex');
          unit = header.chunk + TAG;
          data = head.subarray(p.length);
        }
        pending = Buffer.concat([pending, data]);
        if (suspect) {
          if (pending.length > 16 * unit) throw tampered();
          return cb();
        }
        while (pending.length > unit) {
          const sealed = pending.subarray(0, unit);
          const plain = tryOpen(key, prefix, hh, counter, false, sealed);
          if (plain === null) {
            failNonFinal(sealed);
            return cb();
          }
          if (plain.length > 0) this.push(plain);
          counter += 1;
          pending = pending.subarray(unit);
        }
        cb();
      } catch (e) {
        cb(e as Error);
      }
    },
    flush(cb: TransformCallback) {
      try {
        if (header === undefined) throw new JpstError('truncated', 'jpst: the file ends inside its header');
        finish(this);
        cb();
      } catch (e) {
        cb(e as Error);
      }
    },
  });
}

async function collect(t: Transform, input: Buffer): Promise<Buffer> {
  const out: Buffer[] = [];
  t.on('data', (b: Buffer) => out.push(b));
  const done = new Promise<void>((res, rej) => {
    t.on('end', res);
    t.on('error', rej);
  });
  t.end(input);
  await done;
  return Buffer.concat(out);
}
export const sealBuffer = (key: Buffer, plain: Buffer, o: SealOptions = {}): Promise<Buffer> => collect(sealTransform(key, o), plain);
export const openBuffer = (key: Buffer, sealed: Buffer): Promise<Buffer> => collect(openTransform(key), sealed);

import { createReadStream, createWriteStream, mkdirSync, statSync } from 'node:fs';
import { dirname, join, resolve, sep } from 'node:path';
import { Writable } from 'node:stream';

/**
 * The deterministic ustar of the hosted bundles (spec §3.3): names sorted, mode 0600, uid/gid 0, mtime 0, regular files
 * only, so the same names and bytes always give the same archive. The extractor reads only this subset.
 */
export interface TarFile {
  readonly name: string;
  readonly path: string;
}
const BLOCK = 512;
const SAFE_NAME = /^(?!\/)(?!.*(?:^|\/)\.\.?(?:\/|$))[A-Za-z0-9._@+=,~ -]+(?:\/[A-Za-z0-9._@+=,~ -]+)*$/;

export class TarError extends Error {
  override readonly name = 'TarError';
}

export function checkName(name: string): void {
  if (Buffer.byteLength(name) > 255 || !SAFE_NAME.test(name)) throw new TarError(`tar: unsafe or too long entry name ${JSON.stringify(name.slice(0, 80))}`);
}

function splitName(name: string): { prefix: string; base: string } {
  if (Buffer.byteLength(name) <= 100) return { prefix: '', base: name };
  for (let i = name.lastIndexOf('/'); i > 0; i = name.lastIndexOf('/', i - 1)) {
    const prefix = name.slice(0, i);
    const base = name.slice(i + 1);
    if (Buffer.byteLength(prefix) <= 155 && Buffer.byteLength(base) <= 100) return { prefix, base };
  }
  throw new TarError(`tar: ${JSON.stringify(name.slice(0, 80))} does not fit a ustar header`);
}

const octal = (n: number, width: number): string => `${n.toString(8).padStart(width - 1, '0')}\0`;

export function header(name: string, size: number): Buffer {
  checkName(name);
  if (!Number.isSafeInteger(size) || size < 0 || size > 0o77777777777) throw new TarError(`tar: ${name} is too large for ustar`);
  const { prefix, base } = splitName(name);
  const h = Buffer.alloc(BLOCK);
  h.write(base, 0, 100, 'utf8');
  h.write(octal(0o600, 8), 100, 'ascii');
  h.write(octal(0, 8), 108, 'ascii');
  h.write(octal(0, 8), 116, 'ascii');
  h.write(octal(size, 12), 124, 'ascii');
  h.write(octal(0, 12), 136, 'ascii');
  h.write('        ', 148, 'ascii');
  h.write('0', 156, 'ascii');
  h.write('ustar\0', 257, 'ascii');
  h.write('00', 263, 'ascii');
  h.write(prefix, 345, 155, 'utf8');
  let sum = 0;
  for (const b of h) sum += b;
  h.write(`${sum.toString(8).padStart(6, '0')}\0 `, 148, 'ascii');
  return h;
}

export async function* tarStream(files: readonly TarFile[]): AsyncGenerator<Buffer> {
  const sorted = [...files].sort((a, b) => (a.name < b.name ? -1 : a.name > b.name ? 1 : 0));
  for (let i = 1; i < sorted.length; i++) if (sorted[i]!.name === sorted[i - 1]!.name) throw new TarError(`tar: duplicate entry ${sorted[i]!.name}`);
  for (const f of sorted) {
    const size = statSync(f.path).size;
    yield header(f.name, size);
    let read = 0;
    for await (const chunk of createReadStream(f.path)) {
      read += (chunk as Buffer).length;
      yield chunk as Buffer;
    }
    if (read !== size) throw new TarError(`tar: ${f.name} changed while it was read`);
    if (size % BLOCK !== 0) yield Buffer.alloc(BLOCK - (size % BLOCK));
  }
  yield Buffer.alloc(2 * BLOCK);
}

const field = (h: Buffer, at: number, len: number): string => {
  const raw = h.subarray(at, at + len);
  const z = raw.indexOf(0);
  return raw.subarray(0, z < 0 ? len : z).toString('utf8');
};

export function untarInto(dir: string, onFile?: (name: string) => void): Writable {
  const root = resolve(dir);
  let buf = Buffer.alloc(0);
  let current: { remaining: number; pad: number; out: ReturnType<typeof createWriteStream> } | null = null;
  let ended = false;
  const step = async (): Promise<void> => {
    for (;;) {
      if (current !== null) {
        if (current.remaining > 0) {
          if (buf.length === 0) return;
          const take = Math.min(current.remaining, buf.length);
          const part = buf.subarray(0, take);
          buf = buf.subarray(take);
          current.remaining -= take;
          const out = current.out;
          if (!out.write(part)) await new Promise<void>((r) => out.once('drain', () => r()));
          continue;
        }
        if (buf.length < current.pad) return;
        buf = buf.subarray(current.pad);
        const out = current.out;
        await new Promise<void>((res, rej) => out.end((e?: Error | null) => (e ? rej(e) : res())));
        current = null;
        continue;
      }
      if (ended || buf.length < BLOCK) return;
      const h = buf.subarray(0, BLOCK);
      if (h.every((b) => b === 0)) {
        ended = true;
        return;
      }
      let sum = 0;
      for (let i = 0; i < BLOCK; i++) sum += i >= 148 && i < 156 ? 32 : (h[i] as number);
      if (parseInt(field(h, 148, 8).trim() || '-1', 8) !== sum) throw new TarError('tar: header checksum mismatch');
      if (field(h, 257, 6) !== 'ustar' || field(h, 156, 1) !== '0') throw new TarError('tar: only ustar regular files are accepted');
      const prefix = field(h, 345, 155);
      const name = prefix === '' ? field(h, 0, 100) : `${prefix}/${field(h, 0, 100)}`;
      checkName(name);
      const size = parseInt(field(h, 124, 12), 8);
      if (!Number.isSafeInteger(size) || size < 0) throw new TarError(`tar: bad size for ${name}`);
      const target = join(root, ...name.split('/'));
      if (!target.startsWith(root + sep)) throw new TarError(`tar: ${name} escapes the target`);
      onFile?.(name);
      mkdirSync(dirname(target), { recursive: true, mode: 0o700 });
      buf = buf.subarray(BLOCK);
      current = { remaining: size, pad: (BLOCK - (size % BLOCK)) % BLOCK, out: createWriteStream(target, { flags: 'wx', mode: 0o600 }) };
    }
  };
  return new Writable({
    write(chunk: Buffer, _e, cb) {
      buf = Buffer.concat([buf, chunk]);
      step().then(() => cb(), cb);
    },
    final(cb) {
      step().then(() => cb(ended && current === null ? null : new TarError('tar: the archive ends early')), cb);
    },
  });
}

Rules (P5):
- Every operation reads the head, decides on its pointer, and calls `casState(head.commit, …)`. A rejected CAS
  re-reads: `acquireLease` re-decides from scratch; `commitGeneration` retries only while the new head still has
  `gen = G` and our lease (a ledger append slipped in), else throws `StateConflict`; `appendStateFiles` re-runs `edit`.
  At most `CAS_RETRIES` re-reads, then `StateConflict`.
- A lease is free when null or `until < now` (strictly).
- `commitGeneration` refuses unless the head's lease holder is `holder` and `gen = base.pointer.gen` (StateConflict).
- `rollbackTo`: refuses under a live lease (`StateBusy`); refuses a `k` not in `history`; refuses when
  `history[k].schema` is below `current.schema` (either part) without `withCode`, with
  `rollback below schema <kernel>.<app> needs the code that wrote it: pass --with-code <sha> and set code.lock to it`.

}

}
