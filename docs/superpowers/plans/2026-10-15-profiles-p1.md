# jobpilot Profiles P1 Implementation Plan: profiles and generic rules

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.
>
> **Plan style (same as the v1, freelance and career-sites plans):** each task fixes files, interfaces, exact values
> and test cases; the implementer writes the code test-first (failing test → run → minimal code → run → commit). The
> spec is binding: `docs/superpowers/specs/2026-10-14-jobpilot-profiles-design.md`. This plan covers its §10 steps 1
> and 2 only.

**Goal:** jobpilot serves several people on one machine. Each profile is a complete, isolated home under
`~/.jobpilot/profiles/<id>/`, chosen with `--profile` or the active profile. The existing home becomes one profile
through a reversible, byte-identical `profile adopt`. Every rule built in for one person (residence India, Indian pay,
Bengaluru, one person's titles, letter wording, forbidden names) becomes a profile setting, and the existing user's
outputs stay byte-identical.

**Architecture:**
- A small resolver (`src/app/profiles/root.ts`) turns `--profile` / `active-profile` / `JOBPILOT_HOME` into one home
  directory. Everything below it (`homePaths`, the lock, the due files, the DB, `out/`) is unchanged: a profile *is* a
  home, so isolation comes for free.
- Machine-level state is limited to:
  - `profiles/`;
  - `active-profile`;
  - `pacer.db`, the machine-wide per-host pacer (SQLite, `BEGIN IMMEDIATE`);
  - `backups/`, `removed/` and `adopt.json`;
  - `logs/dashboard.log`.
- The generic rules thread one derived value, `ResidenceScope` (`src/app/geo/residence.ts`), through eligibility, the
  source adapters and the letter. A setting that is absent stays absent in the parsed pack, so pack hashes and step
  keys of the existing profile do not move. Every non-default path is guarded by an explicit "residence is `IN` and the
  setting is absent → the old code path" branch, proven by the byte-identity gate.

**Tech stack:** TypeScript on Node 24 (ESM, strict), zod 4.6.5, better-sqlite3, vitest, commander, hono, yaml, all
already pinned. **No new dependencies.**

## Decisions this plan makes (spec ambiguities resolved)

1. **`JOBPILOT_HOME` keeps its meaning (one home)**, so every existing test and temp-home rehearsal works unchanged. The
   machine root is the new `JOBPILOT_ROOT` (default `~/.jobpilot`). `--profile` together with `JOBPILOT_HOME` is an
   error. A `JOBPILOT_HOME` that holds `profiles/` and no `pack/` is read as a root (a stale plist after adopt still
   runs the active profile instead of an empty home).
2. **Legacy mode:** a root without `profiles/` is today's single home, byte for byte. Nothing changes for the existing
   user until `profile adopt`.
3. **Scheduling stays in IST for every profile in P1.** Run ids (`daily-<IST date>`), due windows and step keys use
   IST, and changing them would break byte-identity. The spec's "07:00 local time" (§7) arrives with the setup wizard
   in P3, as a profile `timeZone` setting whose absent value is `Asia/Kolkata`. The pacer works in UTC epoch
   milliseconds, so time zones never matter to it.
4. **"Serialised through a machine-wide pacer" (§3)** means per-host request spacing is shared by every jobpilot
   process on the machine. Runs of different profiles may overlap; their requests to one host never come closer than
   the larger of the two callers' intervals. Per-company daily request budgets stay per profile run in P1. A shared
   daily budget is listed under Later plans.
5. **Launchd labels:** a profile's jobs are `com.jobpilot.<id>.daily|freelance|coverage`. The dashboard is one
   machine-level job that keeps the label `com.jobpilot.dashboard` and serves every profile. Adopt unloads the four
   legacy labels, then installs the per-profile ones. Unadopt reverses this.
6. **Dashboard switching is navigation only.** Routes live under `/p/<id>/…`. Changing the default profile stays a
   CLI action (`profile use`), so the root needs no state-changing route and no root CSRF secret. CSRF is per profile
   because each profile's token is an HMAC under that profile DB's own secret.
7. **Keychain:** the adopted profile keeps the service `jobpilot`, so no secret moves. Other profiles use
   `jobpilot.<id>`. This is recorded in `profiles/<id>/profile.json`.
8. **Place tables per residence:** the global place table is today's table with India's city and state spellings
   moved to `IN`'s data file. A run loads the base table plus only the residence country's city file, so the owner's
   table is exactly today's. A non-`IN` profile's eligibility also recomputes countries from the location text with its
   own table; for `IN` it uses `posting.remote.countries` exactly as today.
9. **Pay in other currencies and locales** is re-derived in eligibility (which reads the pack) only when the profile
   sets `offers.payLocale` or a floor currency outside INR/USD/EUR/GBP. The normalizer, its `Posting.comp` contract and
   the owner's verdicts are untouched. `fx.yaml` keeps its key `toINR`: the pivot is internal, any number of extra
   currency codes may be listed, and a missing rate for a floor currency is a pack error.
10. **Targets per role family:** one optional `targets.roleFamily` (12 ids from spec §6). When `targets.titles` is
    empty, the family's shipped starter titles stand in. Multi-family search is deferred to P4 with the vocabularies.
11. **Work modes:** the optional `eligibility.workModes` (`remote`, `office`, `hybrid`). When absent, today's rule
    applies (remote, plus office/hybrid in `officeCities`). When present, it drives both eligibility and the letter's
    availability sentence.
12. **Freelance stays India-scoped in P1.** For a profile whose residence is not `IN`, `run-freelance` refuses with a
    named message, and `schedule install` does not install that profile's freelance job. Generic gig eligibility is
    listed under Later plans.
13. **`profile remove` archives** the whole profile directory to `<root>/removed/<id>-<UTC stamp>/` (a rename;
    nothing is deleted) after unloading its jobs. It refuses the active profile and a profile whose lock is live.
    (`archive/` is taken: it is each home's retention archive, and adopt moves it into the profile.)
14. **The watchlist key `hiresInIndia` keeps its name.** Renaming it would change every existing pack and its hash.
    For a profile living elsewhere it means "hires in this profile's country of residence", as documented in
    `schema.ts`; the P3 wizard writes it under that meaning.
15. **Adopt on a copy:** `profile adopt|unadopt --no-launchd` leaves launchd alone, because launchd labels are
    machine-wide. Without it, adopt refuses a root that the installed schedule does not run, so a rehearsal can never
    unload the real jobs.

## Byte-identity protocol (used by every task from Task 1)

The existing profile's outputs are proven unchanged by three checks. A task is not done until all three pass.

1. **Strict golden:** `tests/app/daily-identity.test.ts` with `tests/fixtures/daily-identity.json`, never
   regenerated in this plan. `UPDATE_GOLDEN` is forbidden on this branch. A diff in `git diff main -- tests/fixtures/daily-identity.json` fails
   the review.
2. **Existing suites unchanged:** no existing assertion in `tests/app/eligibility.test.ts`, `scorer.test.ts`,
   `writing.test.ts`, `render.test.ts`, `sources-*.test.ts`, `e2e*.test.ts`, `schedule.test.ts`, `web*.test.ts` is
   edited. New cases are added in new `describe` blocks. `git diff main --stat -- tests/` is reviewed for edits to
   existing expectations.
3. **Real-pack comparison** (Task 0 builds it): `tests/support/real-pack-snapshot.ts` runs, against a **copy** of the
   real pack in a temp home, offline:
   - the daily run on `tests/fixtures/e2e`;
   - `decideEligibility` + `scorePosting` over every posting in `evals/datasets/eligibility.jsonl`;
   - the cover letter fill.
   It writes one JSON snapshot. The baseline snapshot is recorded once from `main` @ `4ebadea`, and each task's
   snapshot must equal it byte for byte. Both files live in `$S/` and are **never committed** (they hold the real
   pack's verdicts).

```ts
import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join, relative, sep } from 'node:path';

/** Every file under `out`, as `"<posix relPath> <sha256>"`, sorted: the documents' bytes, not only their DB rows. */
export function outTreeHashes(out: string): string[] {
  const lines: string[] = [];
  const walk = (dir: string): void => {
    for (const name of readdirSync(dir)) {
      const p = join(dir, name);
      if (statSync(p).isDirectory()) walk(p);
      else lines.push(`${relative(out, p).split(sep).join('/')} ${sha(readFileSync(p).toString('latin1'))}`);
    }
  };
  walk(out);
  return lines.sort();
}
```

```ts
import { cpSync, mkdtempSync, readFileSync, rmSync, writeFileSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { parseArgs } from 'node:util';
import { decideEligibility } from '../../src/app/agents/eligibility.js';
import { scorePosting } from '../../src/app/agents/scorer-lexicon.js';
import { COVER_P4 } from '../../src/app/agents/writing/templates.js';
import { resolvePdftotext } from '../../src/app/kernel.js';
import { offlineProviders } from '../../src/app/offline.js';
import { loadPack } from '../../src/app/pack/load.js';
import { fillP4 } from '../../src/app/render/fill.js';
import { runDaily } from '../../src/app/run.js';
import type { EligibilityVerdict, Posting } from '../../src/app/types.js';
import { outTreeHashes, snapshot } from './identity-snapshot.js';

const root = join(import.meta.dirname, '../..');
const CLOCK = '2026-10-09T01:30:00.000Z';

/**
 * The real-pack comparison (profiles P1 byte-identity protocol, check 3). Everything runs on a COPY of `packDir` in a
 * temp home, offline: the daily run on tests/fixtures/e2e (feeds forced to himalayas, as the strict golden does), every
 * eligibility eval posting through eligibility and the scorer, and the cover letter's availability sentence. The text
 * holds the pack's verdicts, so it is written only under the scratchpad and never committed.
 */
export async function realPackSnapshot(packDir: string): Promise<string> {
  const home = mkdtempSync(join(tmpdir(), 'jobpilot-realpack-'));
  try {
    cpSync(packDir, join(home, 'pack'), { recursive: true });
    writeFileSync(join(home, 'pack/feeds.yaml'), 'enabled: [himalayas]\n');
    const offline = offlineProviders(join(root, 'tests/fixtures/e2e'));
    const r = await runDaily({ home, clock: { now: () => CLOCK }, fetch: offline.fetch, browser: offline.browser, sleep: async () => {}, pdftotext: resolvePdftotext(), codeHash: 'identity0000fixed' });
    const { pack } = loadPack(join(home, 'pack'), {}, { asOf: '2026-10', mode: 'daily' });
    const { contact: _c, answers: _a, ...pub } = pack;
    const decisions = readFileSync(join(root, 'evals/datasets/eligibility.jsonl'), 'utf8').split('\n').filter((l) => l.trim() !== '').map((l) => {
      const { id, input } = JSON.parse(l) as { id: string; input: Posting };
      const d = decideEligibility(input, pub);
      const s = d.verdict === 'eligible' || d.verdict === 'review' ? scorePosting({ posting: input, ...d } as EligibilityVerdict, pub) : null;
      return { id, ...d, score: s?.score ?? null, breakdown: s?.breakdown ?? null };
    });
    const p4 = fillP4(COVER_P4, pack.answers, pack.contact.city, pack.eligibility.officeCities ?? []);
    return `${JSON.stringify({ status: r.report.status, packHash: r.packHash, fullPackHash: r.fullPackHash, db: snapshot(join(home, 'jobpilot.db')), out: outTreeHashes(join(home, 'out')), decisions, p4 }, null, 2)}\n`;
  } finally {
    rmSync(home, { recursive: true, force: true });
  }
}

if (process.argv[1]?.endsWith('real-pack-snapshot.ts')) {
  const { values } = parseArgs({ options: { pack: { type: 'string' }, out: { type: 'string' } } });
  if (values.pack === undefined || values.out === undefined) throw new Error('usage: real-pack-snapshot.ts --pack <dir> --out <file>');
  writeFileSync(values.out, await realPackSnapshot(values.pack), { mode: 0o600 });
}
```

```ts
 * The machine root and its profiles (profiles spec §3). A root without `profiles/` is today's single home (legacy
 * mode, byte for byte); with it, each `profiles/<id>/` is a complete home and `active-profile` names the default.

export const PROFILE_ID = /^[a-z][a-z0-9-]{1,31}$/;
export const RESERVED_PROFILE_IDS: ReadonlySet<string> = new Set(['daily', 'freelance', 'coverage', 'dashboard', 'profiles', 'archive', 'backups', 'logs', 'root']);
export const PROFILES_DIR = 'profiles';
export const ACTIVE_FILE = 'active-profile';

export class ProfileError extends Error {
  override readonly name = 'ProfileError';
}

export function checkProfileId(id: string): string {
  if (!PROFILE_ID.test(id)) throw new ProfileError(`profile id ${JSON.stringify(id)} must be 2-32 characters: a lowercase letter, then lowercase letters, digits or hyphens`);
  if (RESERVED_PROFILE_IDS.has(id)) throw new ProfileError(`profile id ${id} is reserved`);
  return id;
}

export function jobpilotRoot(env: NodeJS.ProcessEnv = process.env): string {
  const r = env['JOBPILOT_ROOT'];
  return r !== undefined && r !== '' ? r : join(env['HOME'] ?? homedir(), '.jobpilot');
}

export const isProfilesRoot = (root: string): boolean => existsSync(join(root, PROFILES_DIR));
export const profileHome = (root: string, id: string): string => join(root, PROFILES_DIR, checkProfileId(id));

export function readActiveProfile(root: string): string | undefined {
  try {
    const id = readFileSync(join(root, ACTIVE_FILE), 'utf8').trim();
    return PROFILE_ID.test(id) && !RESERVED_PROFILE_IDS.has(id) ? id : undefined;
  } catch {
    return undefined;
  }
}

export function writeActiveProfile(root: string, id: string): void {
  checkProfileId(id);
  const tmp = join(root, `${ACTIVE_FILE}.${process.pid}.tmp`);
  writeFileSync(tmp, `${id}\n`, { mode: 0o600 });
  renameSync(tmp, join(root, ACTIVE_FILE));
}

export interface HomeChoice {
  readonly home: string;
  readonly root: string;
  readonly profile: string | null;
  readonly mode: 'explicit' | 'legacy' | 'profile';
}

export function resolveHome(o: { profile?: string | undefined; env?: NodeJS.ProcessEnv } = {}): HomeChoice {
  const env = o.env ?? process.env;
  const explicit = env['JOBPILOT_HOME'];
  let root: string;
  if (explicit !== undefined && explicit !== '') {
    if (!(isProfilesRoot(explicit) && !existsSync(join(explicit, 'pack')))) {
      if (o.profile !== undefined) throw new ProfileError('--profile cannot be combined with JOBPILOT_HOME, which names one home; unset JOBPILOT_HOME (or set JOBPILOT_ROOT instead)');
      return { home: explicit, root: explicit, profile: null, mode: 'explicit' };
    }
    root = explicit;
  } else {
    root = jobpilotRoot(env);
  }
  if (!isProfilesRoot(root)) {
    if (o.profile !== undefined) throw new ProfileError(`${root} has no profiles yet; run "jobpilot profile adopt <id>" (an existing home) or "jobpilot profile create <id>" (a new one) first`);
    return { home: root, root, profile: null, mode: 'legacy' };
  }
  const id = o.profile ?? readActiveProfile(root);
  if (id === undefined) throw new ProfileError(`no active profile in ${root}: run "jobpilot profile use <id>" or pass --profile <id>`);

  if (!existsSync(home)) throw new ProfileError(`no profile ${id} in ${root} ("jobpilot profile list" shows them)`);
  return { home, root, profile: id, mode: 'profile' };
}
```

```ts
import { join } from 'node:path';
```

```ts
import { liveHolder, systemProbe, type ProcessProbe } from '../lock.js';

import { checkProfileId, isProfilesRoot, profileHome, ProfileError, PROFILES_DIR, readActiveProfile, writeActiveProfile } from './root.js';

export const REMOVED_DIR = 'removed';
export const stampOf = (iso: string): string => iso.replace(/\.\d{3}Z$/, 'Z').replace(/[-:]/g, '');

export function createProfile(o: { root: string; id: string; clock: Clock; fromPack?: string }): string[] {
  checkProfileId(o.id);
  if (!isProfilesRoot(o.root) && existsSync(join(o.root, 'pack'))) throw new ProfileError(`${o.root} is a single jobpilot home with a pack; adopt it first: jobpilot profile adopt <id>`);
  const home = profileHome(o.root, o.id);
  if (existsSync(home)) throw new ProfileError(`profile ${o.id} already exists`);
  mkdirSync(join(o.root, PROFILES_DIR), { recursive: true, mode: 0o700 });
  mkdirSync(home, { mode: 0o700 });
  for (const d of ['out', 'logs', 'secrets']) mkdirSync(join(home, d), { mode: 0o700 });
  if (o.fromPack !== undefined) cpSync(o.fromPack, join(home, 'pack'), { recursive: true });
  writeMeta(home, { id: o.id, createdAt: o.clock.now(), keychainService: `jobpilot.${o.id}`, adopted: false });
  const lines = [`created profile ${o.id} at ${home}`];
  if (readActiveProfile(o.root) === undefined) {
    writeActiveProfile(o.root, o.id);
    lines.push(`${o.id} is now the active profile`);
  }
  if (o.fromPack === undefined) lines.push(`next: put a pack in ${join(home, 'pack')} (jobpilot pack import --profile ${o.id}), then jobpilot pack check --profile ${o.id}`);
  return lines;
}

export function useProfile(o: { root: string; id: string }): string[] {
  if (!existsSync(profileHome(o.root, o.id))) throw new ProfileError(`no profile ${o.id} in ${o.root} ("jobpilot profile list" shows them)`);
  writeActiveProfile(o.root, o.id);
  return [`${o.id} is now the active profile`];
}

export function removeProfile(o: { root: string; id: string; clock: Clock; unload: (id: string) => void; probe?: ProcessProbe }): string[] {
  const home = profileHome(o.root, o.id);
  if (!existsSync(home)) throw new ProfileError(`no profile ${o.id} in ${o.root}`);
  if (readActiveProfile(o.root) === o.id) throw new ProfileError(`${o.id} is the active profile; "jobpilot profile use <other>" first`);
  const holder = liveHolder(home, o.probe ?? systemProbe);
  if (holder !== undefined) throw new ProfileError(`${o.id} is running (pid ${holder.pid}, ${holder.command}); try again when it has finished`);
  o.unload(o.id);
  const to = join(o.root, REMOVED_DIR, `${o.id}-${stampOf(o.clock.now())}`);
  mkdirSync(join(o.root, REMOVED_DIR), { recursive: true, mode: 0o700 });
  renameSync(home, to);
  return [`unloaded the launchd jobs of ${o.id}`, `archived ${home} to ${to} (nothing was deleted)`];
}
```

**What moves.** Everything directly under the root except the machine entries:

**Sequence** (`adoptProfile`, all under the root's run lock `withLock(root, 'profile adopt', …)`, which refuses while
any run, rebuild or migrate holds it):
1. Refuse when `profiles/` exists ("already has profiles"), when there is no `pack/` ("nothing to adopt"), or when the
   id is bad.
2. `launchd.before()` unloads the legacy jobs and returns the labels that were loaded (Task 7; `NO_LAUNCHD` here).
3. WAL checkpoint (`PRAGMA wal_checkpoint(TRUNCATE)`) on `jobpilot.db`.
4. Backup to `<root>/backups/adopt-<stamp>/`. `jobpilot.db` is copied with SQLite's online backup (`db.backup()`).
   Every other entry is copied with `cpSync(…, { recursive: true, mode: COPYFILE_FICLONE, verbatimSymlinks: true })`
   (an APFS clone: instant, no extra space until changed). `manifest.json` lists `"<relPath> <size> <sha256>"` for
   every moved file.
5. Write the journal `<root>/adopt.json` `{ id, at, moved, backup, legacyLabelsLoaded }`, **before** the first move,
   so a crash mid-move is undone by `profile unadopt`.
6. `mkdir profiles/<id>` (0700), then `renameSync` each entry (same volume: atomic per entry).
7. Write `profile.json` (`keychainService: 'jobpilot'`, `adopted: true`) and `active-profile`.
8. Verify: the moved tree's manifest equals the pre-move manifest, and `PRAGMA integrity_check` is `ok`.
9. On any error in 6-8: move every moved entry back in reverse order, remove `profile.json`, `profiles/<id>`,
   `profiles/`, `active-profile` and `adopt.json`, call `launchd.restore(loaded)`, and rethrow as `AdoptError`
   naming the backup.
10. `launchd.after(id, loaded)` (Task 7).

**Unadopt** (`unadoptProfile`) reverses it:
- It needs `adopt.json` and exactly one profile, the journal's (others are named and refused).
- It takes that profile's lock and calls `launchd.before(id)` (unloads the profile's jobs and the machine dashboard).
- It checkpoints, backs up to `backups/unadopt-<stamp>/`, and refuses if any target name already exists at the root.
- It moves every entry except `jobpilot.lock*` and `profile.json` back to the root and verifies the manifests.
- After the lock is released it removes `profile.json`, `profiles/<id>`, `profiles/` and `active-profile`, and moves
  `adopt.json` into the unadopt backup.
- Finally `launchd.after(journal.legacyLabelsLoaded)` reinstalls the legacy jobs if they were loaded at adopt.

```ts
import { constants, cpSync, existsSync, mkdirSync, readdirSync, readFileSync, renameSync, rmdirSync, rmSync, statSync, writeFileSync } from 'node:fs';
import { join, relative, sep } from 'node:path';

export const BACKUPS_DIR = 'backups';
const MACHINE: ReadonlySet<string> = new Set([PROFILES_DIR, ACTIVE_FILE, BACKUPS_DIR, 'removed', 'pacer.db', 'pacer.db-wal', 'pacer.db-shm', JOURNAL_FILE, 'jobpilot.lock', 'jobpilot.lock.takeover']);
const TEMP = /^(?:jobpilot\.lock|active-profile|profile\.json)\..+\.tmp$/;
export const isMachineEntry = (name: string): boolean => MACHINE.has(name) || TEMP.test(name);

export const AdoptJournal = z.strictObject({ id: z.string(), at: z.string(), moved: z.array(z.string()), backup: z.string(), legacyLabelsLoaded: z.array(z.string()) });
export type AdoptJournal = z.infer<typeof AdoptJournal>;

export class AdoptError extends ProfileError {}

export interface AdoptLaunchd {
  before(): string[];
  after(id: string, loaded: readonly string[]): void;
  restore(loaded: readonly string[]): void;
}
export interface UnadoptLaunchd {
  before(id: string): void;
  after(loaded: readonly string[]): void;
}
export const NO_LAUNCHD: AdoptLaunchd = { before: () => [], after: () => {}, restore: () => {} };
export const NO_UNADOPT_LAUNCHD: UnadoptLaunchd = { before: () => {}, after: () => {} };

const DB = 'jobpilot.db';
const sha = (p: string): string => createHash('sha256').update(readFileSync(p)).digest('hex');

/** `"<posix relPath> <size> <sha256>"` for every file under `names` (relative to `base`), sorted. */
export function treeManifest(base: string, names: readonly string[]): string[] {
  const out: string[] = [];
  const walk = (p: string): void => {
    const st = statSync(p);
    if (st.isDirectory()) for (const n of readdirSync(p)) walk(join(p, n));
    else out.push(`${relative(base, p).split(sep).join('/')} ${st.size} ${sha(p)}`);
  };
  for (const n of names) walk(join(base, n));
  return out.sort();
}

function checkpoint(dir: string): void {
  if (!existsSync(join(dir, DB))) return;
  const db = new Database(join(dir, DB));
  try {
    db.pragma('wal_checkpoint(TRUNCATE)');
  } finally {
    db.close();
  }
}

async function backup(from: string, names: readonly string[], to: string): Promise<void> {
  mkdirSync(to, { recursive: true, mode: 0o700 });
  for (const n of names) {
    if (n === `${DB}-wal` || n === `${DB}-shm`) continue;
    if (n === DB) {
      const db = new Database(join(from, DB), { readonly: true });
      try {
        await db.backup(join(to, DB));
      } finally {
        db.close();
      }
    } else cpSync(join(from, n), join(to, n), { recursive: true, mode: constants.COPYFILE_FICLONE, verbatimSymlinks: true });
  }
}

const integrityOk = (dir: string): boolean => {
  if (!existsSync(join(dir, DB))) return true;
  const db = new Database(join(dir, DB), { readonly: true });
  try {
    return db.pragma('integrity_check', { simple: true }) === 'ok';
  } finally {
    db.close();
  }
};

export async function adoptProfile(o: { root: string; id: string; clock: Clock; launchd?: AdoptLaunchd; probe?: ProcessProbe; afterMove?: (name: string) => void }): Promise<{ home: string; moved: string[]; backup: string; lines: string[] }> {
  checkProfileId(o.id);
  if (isProfilesRoot(o.root)) throw new AdoptError(`${o.root} already has profiles; adopt runs once`);
  if (!existsSync(join(o.root, 'pack'))) throw new AdoptError(`nothing to adopt: ${o.root} has no pack/`);
  const launchd = o.launchd ?? NO_LAUNCHD;
  const at = o.clock.now();
  const backupRel = `${BACKUPS_DIR}/adopt-${stampOf(at)}`;
  const home = profileHome(o.root, o.id);
  return withLock(o.root, 'profile adopt', async () => {
    const loaded = launchd.before();
    checkpoint(o.root);
    const names = readdirSync(o.root).filter((n) => !isMachineEntry(n)).sort();
    await backup(o.root, names, join(o.root, backupRel));
    const manifest = treeManifest(o.root, names);
    writeFileSync(join(o.root, backupRel, 'manifest.json'), `${JSON.stringify(manifest, null, 2)}\n`, { mode: 0o600 });
    const journal: AdoptJournal = { id: o.id, at, moved: names, backup: backupRel, legacyLabelsLoaded: [...loaded] };
    writeFileSync(join(o.root, JOURNAL_FILE), `${JSON.stringify(journal, null, 2)}\n`, { mode: 0o600 });
    const moved: string[] = [];
    try {
      mkdirSync(join(o.root, PROFILES_DIR), { mode: 0o700 });
      mkdirSync(home, { mode: 0o700 });
      for (const n of names) {
        renameSync(join(o.root, n), join(home, n));
        moved.push(n);
        o.afterMove?.(n);
      }
      writeMeta(home, { id: o.id, createdAt: at, keychainService: 'jobpilot', adopted: true });
      writeActiveProfile(o.root, o.id);
      if (treeManifest(home, names).join('\n') !== manifest.join('\n')) throw new Error('the moved files differ from the manifest');
      if (!integrityOk(home)) throw new Error('the moved database fails PRAGMA integrity_check');
    } catch (e) {
      for (const n of [...moved].reverse()) renameSync(join(home, n), join(o.root, n));
      rmSync(join(home, META_FILE), { force: true });
      if (existsSync(home)) rmdirSync(home);
      if (existsSync(join(o.root, PROFILES_DIR))) rmdirSync(join(o.root, PROFILES_DIR));
      rmSync(join(o.root, ACTIVE_FILE), { force: true });
      rmSync(join(o.root, JOURNAL_FILE), { force: true });
      launchd.restore(loaded);
      throw new AdoptError(`adopt failed and was rolled back (${e instanceof Error ? e.message : String(e)}); the backup is ${join(o.root, backupRel)}`);
    }
    launchd.after(o.id, loaded);
    return {
      home, moved, backup: join(o.root, backupRel),
      lines: [`adopted ${o.root} as profile ${o.id} (${moved.length} entries moved to ${home})`, `backup: ${join(o.root, backupRel)}`, `undo with: jobpilot profile unadopt`],
    };
  }, o.probe ?? systemProbe);
}

export async function unadoptProfile(o: { root: string; clock: Clock; launchd?: UnadoptLaunchd; probe?: ProcessProbe }): Promise<string[]> {
  let journal: AdoptJournal;
  try {
    journal = AdoptJournal.parse(JSON.parse(readFileSync(join(o.root, JOURNAL_FILE), 'utf8')));
  } catch {
    throw new AdoptError(`${o.root} was not adopted by jobpilot (no readable ${JOURNAL_FILE}); nothing to undo`);
  }
  const others = listProfiles(o.root).map((p) => p.id).filter((id) => id !== journal.id);
  if (others.length > 0) throw new AdoptError(`other profiles exist: ${others.join(', ')}; remove them first (jobpilot profile remove <id>)`);
  const launchd = o.launchd ?? NO_UNADOPT_LAUNCHD;
  const home = profileHome(o.root, journal.id);
  const backupRel = `${BACKUPS_DIR}/unadopt-${stampOf(o.clock.now())}`;
  await withLock(home, 'profile unadopt', async () => {
    launchd.before(journal.id);
    checkpoint(home);
    const names = readdirSync(home).filter((n) => n !== META_FILE && !n.startsWith('jobpilot.lock') && !TEMP.test(n)).sort();
    const clash = names.filter((n) => existsSync(join(o.root, n)));
    if (clash.length > 0) throw new AdoptError(`cannot unadopt: ${clash.join(', ')} already exist in ${o.root}`);
    await backup(home, names, join(o.root, backupRel));
    const manifest = treeManifest(home, names);
    for (const n of names) renameSync(join(home, n), join(o.root, n));
    if (treeManifest(o.root, names).join('\n') !== manifest.join('\n')) throw new AdoptError(`the moved files differ from the manifest; the backup is ${join(o.root, backupRel)}`);
  }, o.probe ?? systemProbe);
  rmSync(join(home, META_FILE), { force: true });
  rmdirSync(home);
  rmdirSync(join(o.root, PROFILES_DIR));
  rmSync(join(o.root, ACTIVE_FILE), { force: true });
  renameSync(join(o.root, JOURNAL_FILE), join(o.root, backupRel, JOURNAL_FILE));
  launchd.after(journal.legacyLabelsLoaded);
  return [`${o.root} is a single jobpilot home again (profile ${journal.id} undone)`, `backup: ${join(o.root, backupRel)}`];
}
```

```ts
  readonly uid: number;

  const file = join(o.agentsDir ?? join(homedir(), 'Library', 'LaunchAgents'), `${DAILY_LABEL}.plist`);
  if (!existsSync(file)) return undefined;
  const m = /<key>JOBPILOT_HOME<\/key>\s*<string>([^<]*)<\/string>/.exec(readFileSync(file, 'utf8'));

}

  try {
    return realpathSync(p);
  } catch {
    return p;
  }

  const run = o.run ?? realRunner;
  return {
    before() {
      const runs = installedHome(o);
      if (runs !== undefined && real(runs) !== real(o.root)) throw new Error(`the installed schedule runs ${runs}, not ${o.root}; use --no-launchd for a copy`);
      const loaded = scheduleStatus(legacyOf(o), run).filter((s) => s.loaded).map((s) => s.label);
      if (loaded.length > 0) uninstallSchedule(legacyOf(o), run);
      return loaded;
    },
    after(id, loaded) {
      if (loaded.length > 0) installSchedule(profileOf(o, id), run);
    },
    restore(loaded) {
      if (loaded.length > 0) installSchedule(legacyOf(o), run);
    },
  };
}

  const run = o.run ?? realRunner;
  return {
    before(id) {
      uninstallSchedule({ ...profileOf(o, id), dashboard: true }, run);
    },
    after(loaded) {
      if (loaded.length > 0) installSchedule(legacyOf(o), run);
    },
  };
}
```

```ts
import { closeSync, existsSync, openSync } from 'node:fs';
import { join } from 'node:path';
import Database from 'better-sqlite3';
import type { HostPacer } from '../kernel/broker.js';
import type { Clock } from '../kernel/clock.js';
import { normalizeHost } from '../kernel/policy.js';
import { resolveHome } from './profiles/root.js';

/**
 * The machine-wide politeness pacer (profiles spec §3, §8): every jobpilot process on this Mac, of every profile,
 * spaces its requests to one host through one SQLite file, so more profiles never means more pressure on a host. The
 * rule is createHostPacer's (slot = max(now, last + gap), claimed before sleeping), made atomic across processes by a
 * BEGIN IMMEDIATE transaction. Times are UTC epoch milliseconds from the injected clock.
 */
export type PacerFactory = (minIntervalMs: number, kind: 'http' | 'browser') => HostPacer;

export function pacerFile(env: NodeJS.ProcessEnv = process.env, profile?: string): string {
  const f = env['JOBPILOT_PACER_FILE'];
  if (f !== undefined && f !== '') return f;
  const h = resolveHome({ profile, env });
  return join(h.mode === 'explicit' ? h.home : h.root, 'pacer.db');
}

const DAY_MS = 86_400_000;

export function machinePacer(file: string, minIntervalMs: number, kind: 'http' | 'browser', clock: Clock, sleep: (ms: number) => Promise<void>): HostPacer & { close(): void } {
  if (!existsSync(file)) closeSync(openSync(file, 'a', 0o600));
  const db = new Database(file, { timeout: 10_000 });
  db.pragma('journal_mode = WAL');
  db.exec('CREATE TABLE IF NOT EXISTS host_slots (key TEXT PRIMARY KEY, slot_ms INTEGER NOT NULL)');
  db.prepare('DELETE FROM host_slots WHERE slot_ms < ?').run(Date.parse(clock.now()) - DAY_MS);
  const get = db.prepare('SELECT slot_ms FROM host_slots WHERE key = ?');
  const put = db.prepare('INSERT INTO host_slots (key, slot_ms) VALUES (?, ?) ON CONFLICT (key) DO UPDATE SET slot_ms = excluded.slot_ms');
  const claim = db.transaction((key: string, now: number, gap: number): number => {
    const last = (get.get(key) as { slot_ms: number } | undefined)?.slot_ms;
    const slot = last === undefined ? now : Math.max(now, last + gap);
    put.run(key, slot);
    return slot;
  });
  return {
    async wait(host, wider) {
      const now = Date.parse(clock.now());
      const gap = wider !== undefined && Number.isFinite(wider) && wider > minIntervalMs ? wider : minIntervalMs;
      const slot = claim.immediate(`${kind}:${normalizeHost(host)}`, now, gap);
      if (slot > now) await sleep(slot - now);
    },
    close: () => db.close(),
  };
}

export function machinePacerFactory(file: string, clock: Clock, sleep: (ms: number) => Promise<void>): PacerFactory {
  return (ms, kind) => machinePacer(file, ms, kind, clock, sleep);
}
```

```ts
import { serve, type ServerType } from '@hono/node-server';
import { Hono } from 'hono';
import type { Clock } from '../../kernel/clock.js';
import { listProfiles } from '../profiles/meta.js';
import { profileHome, readActiveProfile } from '../profiles/root.js';
import { buildDashboard, type DashboardDeps } from './server.js';
import { allowedHosts, type Sessions } from './security.js';

export interface RootDeps {
  readonly root: string;
  readonly clock: Clock;
  readonly port?: number | (() => number | undefined);
  readonly busyTimeoutMs?: number;
  readonly gmailConnected?: (home: string) => boolean;
  readonly onSchemaNewer?: () => void;
  readonly resolve?: DashboardDeps['resolve'];
  readonly sessionsOf?: (home: string) => Sessions;
}

/** One dashboard for every profile of a root (profiles spec §3): /p/<id>/… is that profile's own dashboard. */
export function createRootDashboard(deps: RootDeps): Hono {
  const app = new Hono();
  const subs = new Map<string, Hono>();
  const portOf = (): number | undefined => (typeof deps.port === 'function' ? deps.port() : deps.port);
  const ids = (): string[] => listProfiles(deps.root).map((p) => p.id);
  const sub = (id: string): Hono => {
    let s = subs.get(id);
    if (s === undefined) {
      const home = profileHome(deps.root, id);
      s = buildDashboard({
        home, clock: deps.clock, basePath: `/p/${id}`,
        profiles: () => ({ ids: ids(), current: id }),
        ...(deps.port !== undefined ? { port: deps.port } : {}),
        ...(deps.busyTimeoutMs !== undefined ? { busyTimeoutMs: deps.busyTimeoutMs } : {}),
        ...(deps.gmailConnected !== undefined ? { gmailConnected: () => deps.gmailConnected?.(home) ?? false } : {}),
        ...(deps.onSchemaNewer !== undefined ? { onSchemaNewer: deps.onSchemaNewer } : {}),
        ...(deps.resolve !== undefined ? { resolve: deps.resolve } : {}),
        ...(deps.sessionsOf !== undefined ? { sessions: deps.sessionsOf(home) } : {}),
      }, {});
      subs.set(id, s);
    }
    return s;
  };
  app.use('*', async (c, next) => {
    const host = (c.req.header('host') ?? '').toLowerCase();
    if (!allowedHosts(portOf()).has(host) || new URL(c.req.url).host.toLowerCase() !== host) return c.text('This dashboard only answers on 127.0.0.1.', 403);
    await next();
  });
  app.get('/', (c) => {
    const all = ids();
    if (all.length === 0) return c.html('<!doctype html><title>jobpilot</title><p>No profiles yet: run <code>jobpilot profile create &lt;id&gt;</code>.</p>');
    const active = readActiveProfile(deps.root);
    return c.redirect(`/p/${active !== undefined && all.includes(active) ? active : all[0]}/`, 302);
  });
  app.get('/p/:id', (c) => c.redirect(`/p/${c.req.param('id')}/`, 301));
  app.all('/p/:id/*', (c) => {
    const id = c.req.param('id');
    if (!ids().includes(id)) return c.text('no such profile', 404);
    const url = new URL(c.req.url);
    url.pathname = url.pathname.slice(`/p/${id}`.length) || '/';
    return sub(id).fetch(new Request(url, c.req.raw));
  });
  return app;
}

export function serveRoot(deps: RootDeps & { readonly port?: number }, onListen?: (url: string) => void): ServerType {
  const port = deps.port ?? 4317;
  return serve({ fetch: createRootDashboard({ ...deps, port }).fetch, hostname: '127.0.0.1', port }, () => onListen?.(`http://127.0.0.1:${port}/`));
}
```

```ts
/** Every home whose data must stay private; never needs an active profile. */
export function privacyHomes(env: NodeJS.ProcessEnv = process.env): { label: string; home: string }[] {
  const explicit = env['JOBPILOT_HOME'];
  if (explicit !== undefined && explicit !== '' && !(isProfilesRoot(explicit) && !existsSync(join(explicit, 'pack')))) return [{ label: 'home', home: explicit }];
  const root = explicit !== undefined && explicit !== '' ? explicit : jobpilotRoot(env);

  try {
    const v = parse(readFileSync(join(home, 'pack', file), 'utf8')) as unknown;

const group = (n: number, indian: boolean): string => {
  const s = String(n);
  if (!indian) return s.replace(/\B(?=(\d{3})+(?!\d))/g, ',');
  const last3 = s.slice(-3);
  const rest = s.slice(0, -3);
  return rest === '' ? last3 : `${rest.replace(/\B(?=(\d{2})+(?!\d))/g, ',')},${last3}`;

  const v = yamlAt(home, 'contact.yaml')['phone'];
  return typeof v === 'string' ? v.replace(/\D/g, '') : '';

export function privacyTermsOf(home: string): string[] {
  const naming = yamlAt(home, 'naming.yaml');
  const contact = yamlAt(home, 'contact.yaml');
  const floor = (yamlAt(home, 'offers.yaml')['floor'] as { amount?: unknown } | null | undefined)?.amount;
  const phone = phoneOf(home);
  const terms = [
    ...strings(naming['forbiddenTerms']),
    ...strings(contact['name']),
    ...strings(contact['email']),
    ...(phone.length >= 7 ? [phone] : []),
    ...strings(contact['links']),
    ...(typeof floor === 'number' && Number.isSafeInteger(floor) ? [String(floor), group(floor, false), group(floor, true)] : []),
  ].map((t) => t.trim().toLowerCase());
  return [...new Set(terms)].filter((t) => t.length >= 4);
}

export function scanForTerms(dir: string, homes: readonly { label: string; home: string }[]): string[] {
  const sets = homes.map((h) => ({ label: h.label, terms: privacyTermsOf(h.home), phone: phoneOf(h.home) }));
  const hits: string[] = [];
  const walk = (p: string): void => {
    for (const name of readdirSync(p).sort()) {
      if (name === 'node_modules' || name === '.git') continue;
      const f = join(p, name);
      if (statSync(f).isDirectory()) {
        walk(f);
        continue;
      }
      const text = readFileSync(f, 'utf8').toLowerCase();
      const digits = text.replace(/\D/g, '');
      for (const s of sets) s.terms.forEach((t, i) => {
        if (text.includes(t) || (t === s.phone && t.length >= 7 && digits.includes(t))) hits.push(`${relative(dir, f).split(sep).join('/')} (${s.label}, term #${i + 1})`);
      });
    }
  };
  walk(dir);
  return hits;
}
```

```ts
  readonly alias: ReadonlyMap<string, string>;
  readonly re: RegExp;
  /** The spellings that name a country by name (not a city or state): India's are india and bharat. */

  readonly offices: Readonly<Record<string, OfficeCity>>;
  readonly states: ReadonlySet<string>;
}

export function placeTable(code: string): PlaceTable {
  let t = tables.get(code);

    offices: c?.offices ?? {},
    states: new Set(c?.states ?? []),
  };
  tables.set(code, t);
  return t;
}
```

```ts
import { codeOfCountry, countryOfCode } from '../text/norm.js';
import { countryData, placeTable, regionsOf, type PlaceTable } from './places.js';

export interface ResidenceScope {
  readonly code: string;
  readonly country: string;
  readonly display: string;
  readonly token: string;
  readonly regions: ReadonlySet<string>;
  readonly utcOffsets: readonly number[];
  readonly zoneWord: RegExp | null;
  readonly offsetRe: RegExp | null;
  readonly nameWord: RegExp;
  readonly nameLoose: RegExp;
  readonly benefitsNote: string;
  readonly table: PlaceTable;
  readonly isDefault: boolean;
}

const IST_WORD = /\bIST\b/;
const IST_OFFSET = /\b(?:utc|gmt)\s*\+\s*0?5:?30\b/i;
const esc = (s: string): string => s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
const offsetRe = (offsets: readonly number[]): RegExp | null => {
  if (offsets.length === 0) return null;
  const forms = offsets.map((o) => {
    const sign = o < 0 ? '-' : '\\+';
    const h = Math.trunc(Math.abs(o));
    const m = Math.round((Math.abs(o) - h) * 60);
    return m === 0 ? `${sign}\\s*0?${h}(?::?00)?` : `${sign}\\s*0?${h}:?${String(m).padStart(2, '0')}`;
  });
  return new RegExp(`\\b(?:utc|gmt)\\s*(?:${forms.join('|')})\\b`, 'i');
};

const cache = new Map<string, ResidenceScope>();
export function residenceScope(code = 'IN'): ResidenceScope {
  const hit = cache.get(code);
  if (hit !== undefined) return hit;
  const country = countryOfCode(code);
  if (country === null) throw new Error(`unknown country code ${code}`);
  const data = countryData(code);
  const isDefault = code === 'IN';
  const names = [country];
  const s: ResidenceScope = {
    code,
    country,
    display: data?.display ?? country.replace(/(^|\s)\p{L}/gu, (c) => c.toUpperCase()),
    token: country.replace(/\s+/g, '-'),
    regions: new Set([...(data?.regions ?? regionsOf(code)), 'worldwide']),
    utcOffsets: data?.utcOffsets ?? [],
    zoneWord: isDefault ? IST_WORD : data !== undefined && data.zoneWords.length > 0 ? new RegExp(`\\b(?:${data.zoneWords.map(esc).join('|')})\\b`) : null,
    offsetRe: isDefault ? IST_OFFSET : offsetRe(data?.utcOffsets ?? []),
    nameWord: isDefault ? /\bindia\b/i : new RegExp(`\\b(?:${names.map(esc).join('|')})\\b`, 'i'),
    nameLoose: isDefault ? /india/i : new RegExp(`(?:${names.map(esc).join('|')})`, 'i'),
    benefitsNote: data?.benefitsNote ?? 'B2B contractor: no employee benefits',
    table: placeTable(code),
    isDefault,
  };
  cache.set(code, s);
  return s;
}

export const DEFAULT_RESIDENCE: ResidenceScope = residenceScope('IN');
export const inScope = (scope: ResidenceScope, places: readonly string[]): boolean => places.some((c) => c === scope.country || scope.regions.has(c));

/** The display name behind a reason token: 'india' → 'India', 'united-states' → 'United States'; an unknown token as it is. */
export function countryDisplayOfToken(token: string): string {
  const code = codeOfCountry(token.replace(/-/g, ' '));
  return code === null ? token : residenceScope(code).display;
}
```

- **Plausibility:** the yearly amount converted to INR through `fx.toINR` must lie within the normalizer's INR bounds

```ts
  en: { group: /,/g, decimal: '.' }, de: { group: /\./g, decimal: ',' }, nl: { group: /\./g, decimal: ',' }, es: { group: /\./g, decimal: ',' },
  it: { group: /\./g, decimal: ',' }, fr: { group: /[\s  ]/g, decimal: ',' }, pl: { group: /[\s  ]/g, decimal: ',' }, sv: { group: /[\s  ]/g, decimal: ',' },
};
/** "60.000,50" (de) → 60000.5; "60,000.50" (en) → 60000.5; "60k" → 60000; null when not a number in this locale. */
export function localNumber(token: string, locale: PayLocale): number | null {
  const m = /^(\d{1,3}(?:[.,\s  ]\d{3})*|\d+)(?:[.,](\d{1,2}))?\s*([kK])?$/.exec(token.trim());
  if (m === null) return null;
  const { group, decimal } = GROUP[locale];
  const whole = (m[1] as string).replace(group, '');
  if (!/^\d+$/.test(whole)) return null;
  const frac = m[2] !== undefined && token.includes(decimal) ? Number(`0.${m[2]}`) : 0;
  const n = (Number(whole) + frac) * (m[3] !== undefined ? 1000 : 1);
  return Number.isFinite(n) ? n : null;
}
```
